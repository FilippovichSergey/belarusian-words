# Малюнкі праз дадатак Gemini, без API

Малюнкі малюе дадатак Gemini па вашай падпісцы. API і аплата не патрэбныя. Скрыпты рыхтуюць спіс слоў і загружаюць гатовыя малюнкі на сайт.

## 1. Стварыце Gem адзін раз

1. Адкрыйце [gemini.google.com](https://gemini.google.com), злева **Gems**, потым **New Gem**.
2. Назва: `Беларускія карткі`.
3. У поле **Instructions** устаўце ўвесь тэкст з блока ніжэй.
4. Націсніце **Save**.

```text
Ты ілюстратар картак для слоўніка беларускай мовы.

Я дасылаю нумараваны спіс беларускіх слоў і выразаў з перакладам і сэнсам.
Для КОЖНАГА пункта, строга па парадку:
1. Напішы адзін радок: «N. слова».
2. Створы адзін квадратны малюнак з прапорцыямі 1:1.

Парадак і колькасць:
- Адзін пункт — адзін асобны малюнак. Ніколі не змяшчай некалькі слоў на адным малюнку і не рабі калажы.
- Не прапускай пункты і не мяняй парадак.
- Калі ўсе пункты не змяшчаюцца ў адзін адказ, спыніся пасля апошняга гатовага і напішы, з якога нумара працягнуць. Працягвай, калі я напішу «далей».

Стыль, аднолькавы для ўсіх малюнкаў:
Flat vector illustration, soft pastel colors, clean white background, simple friendly shapes, centered composition, suitable as a flashcard picture.

Змест:
- На малюнку не павінна быць ніякага тэксту: ні літар, ні лічбаў, ні подпісаў, ні вадзяных знакаў.
- Малюнак мусіць паказваць значэнне слова так, каб па ім можна было здагадацца пра слова. Арыентуйся на пераклад і сэнс, а не на гучанне беларускага слова.
- Назоўнік: сам прадмет ці з'ява. Дзеяслоў: чалавек ці жывёла, якія робяць гэта дзеянне. Прыметнік: прадмет з гэтай якасцю. Абстрактнае слова ці выраз: простая зразумелая сцэна.
- Цытата ці прыказка: адна сімвалічная сцэна пра яе сэнс.
- Без жорсткіх, страшных ці непрыстойных сцэн і без вядомых людзей.
```

Калі Gem не малюе малюнкі, устаўце гэты ж тэкст у пачатак звычайнага чата з Gemini, а пасля яго спіс слоў.

## 2. Падрыхтуйце пачак слоў

```bash
npm run images:batch -- 10
```

Скрыпт выбірае 10 апублікаваных слоў без малюнка і стварае папку `images-batch/<дата-час>/` з двума файламі:

- `prompt.txt` — тэкст для Gemini;
- `words.json` — якое слова пад якім нумарам.

Пачынайце з 10 слоў. Калі Gemini спраўляецца, можна да 20–30. Колькасць малюнкаў у дзень абмежаваная вашым тарыфам Gemini.

## 3. Згенеруйце малюнкі

1. Адкрыйце Gem **Беларускія карткі**.
2. Устаўце ўвесь тэкст з `prompt.txt` і адпраўце.
3. Калі Gemini спыніўся раней, напішыце «далей».
4. Калі нейкі малюнак не падабаецца, папрасіце перарабіць менавіта яго: «перарабі 4».

## 4. Спампуйце малюнкі

Спампоўвайце **па парадку, ад 1 да апошняга**, і захоўвайце ў тую ж папку `images-batch/<дата-час>/`. Скрыпт супастаўляе малюнкі са словамі па часе спампоўкі.

Калі нейкі малюнак прапушчаны ці спампаваны не па парадку, перайменуйце ўсе файлы па нумары слова: `1.png`, `2.png` і г.д. Тады скрыпт возьме нумар з назвы.

## 5. Праверце і загрузіце

```bash
npm run images:upload -- images-batch/<дата-час>
```

Скрыпт нічога не загружае, а паказвае, якое слова атрымае які малюнак, і стварае `preview.html` для праверкі ў браўзеры. Калі ўсё правільна:

```bash
npm run images:upload -- images-batch/<дата-час> --yes
```

Малюнкі сціскаюцца ў WebP 768×768 і загружаюцца ў Supabase. На сайце яны з'яўляюцца адразу. Словы, у якіх малюнак ужо ёсць, прапускаюцца. Каб замяніць іх малюнкі, дадайце `--force`.

Папка `images-batch/` не трапляе ў git.
